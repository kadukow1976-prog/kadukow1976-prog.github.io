# Android Control Hub — Windows
Отдельный сервисный центр Android для Windows 10/11. Реальная работа с подключённым **авторизованным** телефоном через официальные Google Android Platform Tools (ADB/Fastboot).

**[Скачать Windows EXE (beta)](https://github.com/kadukow1976-prog/kadukow1976-prog.github.io/releases/tag/android-control-hub-windows-0.1.0)**

## Функции
Диагностика Android, батареи, памяти, сборки; список и поиск пакетов; проверка заявленных прав наложения окон и автозапуска; очистка только кэша при поддержке Android; очистка данных, остановка, отключение, включение и удаление сторонних приложений для текущего профиля — **с подтверждением**; установка APK и split APK; экспорт APK; передача и копирование разрешённых файлов; Fastboot (только чтение параметров); отчёты JSON и локальный журнал.

Установка ADB/Fastboot доступна в программе по запросу с **dl.google.com**. Приложению нужны разрешённая USB-отладка и согласие владельца устройства. Нет FRP/аккаунт-обхода, чтения паролей других программ, root, изменения IMEI или обещания полного образа Android.

Проект собирается в GitHub Actions под Windows. Исходный пакет с Python/Tkinter без сторонних зависимостей для запуска, тестами и README хранится в [AndroidControlHub-Windows-Source.zip](./AndroidControlHub-Windows-Source.zip). Путь внутри архива: `src/app.py` и `src/ach_core.py`. Для сборки: `BUILD-EXE.cmd`.

**Статус:** тестовая версия, 10 автоматических тестов логики, тест устройства на конкретном OnePlus ожидается. EXE без цифровой подписи.
