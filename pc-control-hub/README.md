# Android Control Hub — Windows 0.2.0
Отдельный сервисный центр Android для Windows 10/11. Реальная работа с подключённым **авторизованным** телефоном через официальные Google Android Platform Tools (ADB/Fastboot).

**[Скачать Windows EXE (beta)](https://github.com/kadukow1976-prog/kadukow1976-prog.github.io/releases/tag/android-control-hub-windows-0.2.0)**

## Функции
Диагностика Android, батареи, памяти, сборки; список и поиск пакетов; проверка заявленных прав наложения окон и автозапуска; очистка только кэша при поддержке Android; очистка данных, остановка, отключение, включение и удаление сторонних приложений для текущего профиля — **с подтверждением**; установка APK и split APK; экспорт APK; передача и копирование разрешённых файлов; Fastboot (только чтение параметров); отчёты JSON и локальный журнал.

**Новое в 0.2:** при запуске программа автоматически проверяет ADB, Fastboot и необходимые DLL. При их отсутствии самостоятельно скачивает официальный Android Platform Tools с **dl.google.com** по HTTPS, проверяет состав ZIP и PE-заголовки, устанавливает в `%LOCALAPPDATA%\\AndroidControlHub\\platform-tools` без администратора, сохраняет SHA-256 перечень и повторно ищет устройства. Неполную установку можно восстановить кнопкой «Восстановить ADB/Fastboot». При отсутствии интернета программа продолжает работать, показывает ошибку и разрешает вручную указать путь. Приложению нужны разрешённая USB-отладка и согласие владельца устройства. Нет FRP/аккаунт-обхода, чтения паролей других программ, root, изменения IMEI или обещания полного образа Android.

Проект собирается в GitHub Actions под Windows. Репозиторий хранит базовый архив версии 0.1 `AndroidControlHub-Windows-Source.zip`; версия 0.2 воспроизводимо получается из него с помощью `upgrade_0_2.py` и тестируется файлом `test_bootstrap_0_2.py`. Архив актуальных исходников 0.2 публикуется в GitHub Release рядом с EXE. Также можно взять [переносимый исходный пакет](https://github.com/kadukow1976-prog/kadukow1976-prog.github.io/releases/tag/android-control-hub-windows-0.2.0).

**Статус:** тестовая версия, 17 автоматических тестов логики и восстановления зависимостей, тест устройства на конкретном OnePlus ожидается. EXE без цифровой подписи.
