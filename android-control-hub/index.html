Частые проблемы

Реклама появляется поверх других приложений

Проверьте недавно установленные приложения и разрешение «Показывать поверх других приложений». Удалите подозрительные программы и перезагрузите телефон. Не отключайте неизвестные системные компоненты без проверки.

Браузер сам открывает рекламные вкладки

Проверьте разрешения на уведомления для сайтов, нежелательные вкладки и список недавно установленных программ. Настройки Chrome: «Настройки сайтов», затем «Уведомления» и «Всплывающие окна и переадресация».

Приложение не удаётся удалить

Проверьте права администратора устройства и службы специальных возможностей. Если обычное удаление не работает, попробуйте безопасный режим через меню питания телефона. Способ запуска зависит от производителя.

Когда нужен заводской сброс?

Только после резервного копирования и если обычные способы не помогают. Сброс удаляет локальные данные и может потребовать ранее привязанный Google-аккаунт (FRP). Сайт не запускает сброс — меню открывается вручную в настройках Android.

    Ранее 0.3.2: понятное сообщение об отказе CLEAR_APP_USER_DATA при полной очистке на Android 16 и безопасное открытие системных настроек приложения для ручного удаления данных. Программа не подменяет очистку удалением.
    Ранее в 0.3.1: тайм-аут при очистке кэша на Android 16 теперь обозначен как неопределённый результат. При ошибке одного приложения программа автоматически открывает его системные настройки на телефоне; есть отдельная кнопка «Настройки». Полная очистка данных вместо кэша не выполняется.

ADB/Fastboot теперь устанавливаются автоматически при первом запуске, если их нет или комплект неполный. Проверяются файлы официального архива Google; отсутствие интернета не мешает вручную настроить путь. USB-отладка требует разрешения владельца телефона. Shizuku для ПК не нужен.

    Android Hub 0.8.1 PRO — уточнение защиты

    Используйте 0.8.1: доработано исключение обновлённых системных приложений из Shizuku-операций и сохранение нескольких записей журнала. Не устанавливайте первоначальную 0.8 для обслуживания клиентских устройств.

    Новое в 0.8.1 PRO — Shizuku и Windows ADB

    В нативном APK появился сервисный режим: выбор пользовательских приложений, предпросмотр операций, соединение с Shizuku через официальный UserService, очистка кэша / данных и отключение с отдельным подтверждением. Для полной очистки требуется PIN/пароль через системный диалог Android. Все результаты выводятся в журнал.

    Второй вариант — экспорт Windows ADB-сценария, который выполняется только после разрешения отладки и ручного запуска. Для работы через Shizuku установите и запустите Shizuku, предоставьте приложению разрешение. Root не требуется. Эти возможности требуют тестирования на конкретной прошивке.

    Сохранено из 0.7 — перенос файлов и восстановление

    В нативном APK добавлен раздел «Перенос и резервное копирование»: передача файлов на Android и Windows через системный Quick Share, USB-MTP инструкция, экспорт списка приложений и выбранных документов в ZIP, восстановление файлов в выбранную папку, список программ для переустановки из Google Play, отправка ссылок на приложения и экспорт APK без личных данных, когда приложение не использует split APK.

    ZIP не зашифрован. Пароли, защищённые данные сторонних приложений и полный образ Android не копируются — для них используйте резервное копирование Google/производителя. Все отправки и установки требуют подтверждения владельца.

    Сохранено из 0.6 — контроль приложений

    APK автоматически анализирует установленные программы при открытии раздела: игры, приложения с заявленным наложением поверх других окон, возможный автозапуск и объявленные службы планировщика. Отдельный список с отметками, поиском и системными действиями по выбранным приложениям.

    Удаление, отключение, очистка кэша или данных выполняются через настройки Android с вашим подтверждением для каждой программы. Личные документы можно сохранить в выбранную папку либо удалить после двойного согласия. Скрытые задачи и закрытые файлы других приложений обычный APK не видит.

    Сохранено из 0.5 — запрос диагностических разрешений

    В приложении откройте «Центр разрешений» и нажмите «Запросить все применимые разрешения для диагностики». Android отдельно покажет системные запросы: контакты, SIM, камера, микрофон, местоположение, Bluetooth и уведомления. Можно отказать; специальные права Usage Access, root и системные привилегии это не выдаёт.

    Сохранено из 0.4 — центр разрешений

    В Android-клиенте добавлены отдельные проверки SIM и связи, камеры, микрофона, GPS, Bluetooth и уведомлений. Разрешения выдаются пользователем только при соответствующей проверке. Доступ к истории приложений (Usage Access) — отдельная системная настройка; root и системные права обычным APK не предоставляются.

    История активности из 0.3 — сохранена

    История открытий и закрытий экранов приложений и запуски/остановки foreground-служб, если Android предоставляет события. Фильтры за 1 час, 24 часа, 3 дня, поиск по приложениям и экспорт CSV.

    Откройте в APK раздел «Журнал активности» из «Обзора» или «Приложений», затем выдайте «Доступ к статистике использования» через системные настройки Android. Не все скрытые процессы и фоновые задания доступны через Usage Events.

    Обновление с предыдущих версий

    Тестовый APK может быть подписан другим отладочным ключом. Если Android выдаёт ошибку несовпадения подписей, сохраните экспортированные файлы, удалите старое приложение и установите 0.8.1. Не отключайте проверки подписей.

    Установка и права

    1. Скачайте APK с GitHub Releases и откройте загрузку на телефоне.
    2. Если Android попросит, однократно разрешите установку из выбранного источника.
    3. Откройте клиент: диагностика работает без доступа к контактам и файлам.
    4. Для VCF отдельно разрешите «Контакты», для передачи файлов выберите документы вручную.
    5. Для журнала активности отдельно разрешите «Доступ к статистике использования» в настройках Android, затем обновите историю.
    Тестовый выпуск

    APK не даёт root, Device Owner, автоматического управления системой или доступа к паролям. Тестовая подпись может отличаться от предыдущих версий: для установки 0.8.1 может потребоваться удалить старое приложение. Массовое использование возможно после испытаний и подписанной release-сборки.
